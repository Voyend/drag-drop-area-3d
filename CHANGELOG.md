# Changelog

All notable changes to the `DragDropArea3D` project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-09-04

### Added
- Initial release of `DragDropArea3D`.
- Native 2D GUI Drag & Drop integration for 3D spaces.
- Optional 3D physics raycasting for true occlusion checking.
- Fallback distance check when raycasts are disabled.
- Performance optimizations (frame skipping, deferred updates).
- Editor and runtime debug visualizations (polygon and bounding rect).
